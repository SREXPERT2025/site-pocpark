# Visual Brief Template

Use this compact shape before generating a ROSPARK page visual.

```text
Use case: infographic-diagram
Asset type: wide website explainer image, 16:9, for ROSPARK page <route>
Audience: <who the page is for>
Primary message: <one sentence>
Scene: modern Russian parking facility matching the page context
Key objects: <barrier/camera/terminal/dashboard/vehicle/object type>
Flow blocks:
1. <step or benefit>
2. <step or benefit>
3. <step or benefit>
4. <step or benefit>
CTA hint: "Обсудить проект" or page-specific equivalent
Style: polished B2B infographic, ROSPARK blue/orange/white palette, clean panels, realistic equipment, no clutter
Text rules: Russian labels only, large readable headings, avoid tiny critical text
Avoid: fake customer names, fake certificates, unsupported numbers, unrelated city/government branding, watermarks
```
