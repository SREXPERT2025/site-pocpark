## Правила

- Использовать только существующие относительные адреса из этого каталога.
- Если пользователь просит ссылку короткой фразой, учитывать тему предыдущих
  сообщений диалога.
- Давать точный адрес сразу, а не отвечать только «в разделе сайта».
- Не придумывать страницы, якоря и параметры URL.
- Для заявки использовать `/quiz`. Для просмотра интерфейсов использовать
  только страницы раздела `/demo`.
