# AI-виджет РОСПАРК — claim ledger v1

Дата: 2026-07-27
Статус: кандидат на утверждение владельцем.

## Правила статусов

- `ALLOW` — можно сообщать без дополнительной оговорки.
- `CONDITIONAL` — можно описывать только как проектный сценарий.
- `OWNER_REVIEW` — до подтверждения использовать нельзя.
- `DENY` — запрещено обещать или раскрывать.

## Фраза границы знаний

Если разрешённого утверждения нет:

> Это нужно проверить со специалистом для конкретной конфигурации объекта.

Можно дополнительно перечислить исходные данные, необходимые для проверки, но
нельзя заранее сообщать положительный результат.

## Правило для кейсов

Кейс подтверждает только сведения своей опубликованной карточки. Он не
подтверждает:

- универсальный срок;
- типовую цену;
- результат на другом объекте;
- наличие той же интеграции в текущей версии продукта;
- суммарное количество реализованных объектов.
