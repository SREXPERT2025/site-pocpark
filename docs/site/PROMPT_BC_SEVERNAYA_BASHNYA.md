# Промт для изображения БЦ «Северная башня»

## Основной промт

Фотореалистичная архитектурная рекламная фотография вымышленного московского бизнес-центра премиум-класса «Северная башня». Современная стеклянная высотная башня с выразительным главным входом, светлым двухсветным лобби и аккуратной зоной ресепшн, рядом виден организованный въезд на парковку со шлагбаумом и камерой распознавания автомобильных номеров. Раннее утро, мягкий естественный свет, чистая деловая атмосфера, графитовые, холодно-синие и нейтрально-бежевые оттенки, реалистичные материалы и отражения, архитектурная съёмка уровня международного девелопера, объектив 28–35 мм, естественная перспектива, высокая детализация без чрезмерного HDR.

Композиция горизонтальная 16:9 для экрана входа на сайт: главный объект и архитектурные детали расположены преимущественно слева, справа оставить спокойное затемнённое негативное пространство для интерфейса авторизации. Изображение должно хорошо выдерживать тёмный сине-графитовый градиент поверх фотографии и обрезку на desktop и mobile. Допустимы несколько небольших силуэтов деловых людей вдали для масштаба, без узнаваемых лиц.

## Негативный промт

Без реальных логотипов и брендов, без читаемых вывесок и текста, без водяных знаков, без интерфейса сайта внутри изображения, без QR-кодов, без крупных лиц, без читаемых автомобильных номеров, без фантастической архитектуры, без деформированных машин и людей, без перенасыщенных цветов, без киберпанка, без неона, без снега и экстремальной погоды.

## Параметры

- Соотношение сторон: 16:9.
- Рекомендуемый размер: не менее 1920×1080.
- Назначение: фон левой части экрана входа в кабинет арендатора.
- Важное: название «Северная башня» выводится живым HTML-текстом поверх изображения, а не генерируется внутри картинки.
