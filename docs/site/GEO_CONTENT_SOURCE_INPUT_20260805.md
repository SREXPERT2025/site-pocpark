## Как заполнять

- В репозитории фиксируется ссылка или идентификатор источника, а не закрытый
  договор, персональные данные или коммерческая тайна.
- Значение можно публиковать только при статусе `APPROVED`.
- `CANDIDATE` означает, что формулировку нельзя переносить в visible copy или
  JSON-LD.
- При отсутствии источника поле остаётся пустым; догадки запрещены.

## Минимальный пакет от владельца

Чтобы начать первый содержательный выпуск, достаточно:

1. подтвердить или отклонить `SRC-001`–`SRC-003` для главной;
2. передать актуальный утверждённый паспорт шлагбаумов для `SRC-004` и
   `SRC-005`;
3. назвать редакционного владельца статьи и, если известна, исходную дату
   публикации;
4. при выборе кейса вместо одной из первых трёх страниц — дать карточку объекта
   с городом, типом объекта, составом оборудования и разрешённым названием
   клиента.

До заполнения источников текущие подтверждённые формулировки сохраняются, а
новые факты в metadata, visible copy и schema не добавляются.
