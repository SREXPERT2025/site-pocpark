# РОСПАРК — структура сайта

Статус: рабочая документация v1  
Дата: 2026-05-03  
Проект: `rospark-frontend`

## Назначение документа

Этот документ фиксирует текущую карту сайта РОСПАРК, основные маршруты, смысл разделов и файлы, которые обычно отвечают за соответствующие страницы. Документ нужен для быстрых правок, передачи контекста ИИ-агентам и безопасного развития сайта.

## Технологическая основа

Сайт построен на Next.js 14 с App Router. Основные страницы находятся в папке `app/`. Общие компоненты находятся в `app/components/`, `components/`, `content/`, `config/` и `lib/` в зависимости от назначения.

## Мобильная проверка

Обязательные ширины:

- 375 px
- 390 px
- 400 px
- 414 px
- 430 px

Критерии:

- нет горизонтального скролла;
- крупные заголовки не вылезают за карточки;
- меню открывается и прокручивается;
- формы помещаются в экран;
- кнопки доступны;
- изображения не ломают ширину;
- карточки оборудования и объектов не раздвигают layout.
