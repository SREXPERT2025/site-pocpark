# AI-виджет РОСПАРК: production-архитектура

Дата фиксации: 28.07.2026

Статус: утверждённая целевая схема, подготовка релизного пакета

Публичный домен: `https://www.роспарк.рф`
AI-контур: Mac Studio

## 1. Цель

Публичный AI-виджет помогает посетителю:

1. разобраться в сценариях автоматизации парковки;
2. уточнить требования к объекту;
3. перейти к релевантному разделу сайта;
4. при готовности передать реальную заявку отделу продаж.

В публичном интерфейсе нет формулировок «тест», «закрытый тест»,
«демо-режим» и запрета вводить реальные данные. Тестовые обращения
сотрудников отмечаются самими сотрудниками словом `TEST` в имени или задаче
и закрываются в реестре с результатом «Тест».

## 2. Разделение ответственности

### VPS РОСПАРК

- отдаёт сайт и интерфейс виджета;
- принимает запросы только со своего разрешённого origin;
- проверяет размер, формат и частоту запросов;
- хранит журнал диалогов;
- принимает согласие на обработку персональных данных;
- регистрирует заявки в рабочем реестре лидов;
- ставит уведомления в существующий outbox для MAX;
- предоставляет Андрею и Сергею общий служебный просмотр;
- показывает безопасный аварийный ответ при недоступности AI-контура.

### Mac Studio

- содержит базу знаний, правила, FAQ и маршрутизацию;
- выбирает быстрый ответ, шаблон или локальную модель;
- формирует текст ответа и безопасные ссылки;
- не принимает прямые запросы из браузера;
- не хранит рабочий реестр лидов;
- не получает имя и телефон из формы заявки.

Preview и production работают отдельными loopback-процессами:

- `127.0.0.1:8787` — preview для `srtestrealme.ru`;
- `127.0.0.1:8788` — production-профиль для публичного VPS.

Production-процесс использует отдельный env-файл и отдельный bearer secret.
Это позволяет продолжать внутреннюю проверку preview без переключения
публичного консультанта в тестовый режим.

Изменение FAQ, промптов, маршрутизации, правил и локальной модели требует
только обновления AI-сервиса на Mac Studio. Изменение интерфейса, публичного
API, полей заявки, журнала или служебного кабинета требует обычного релиза
сайта на VPS.

## 3. Схема обмена

```text
Посетитель
  -> HTTPS /api/ai-widget/* на VPS
  -> проверка origin, payload, rate limit, session
  -> журнал вопроса на VPS
  -> закрытый HTTPS-канал VPS -> AI gateway на Mac Studio
  -> правила / FAQ / каскад / локальная модель
  -> ответ на VPS
  -> журнал ответа на VPS
  -> потоковый ответ посетителю
```

Браузер не знает адрес Mac Studio, секрет шлюза и адрес Ollama.

## 4. Режимы

| Параметр | Preview | Production |
|---|---|---|
| `AI_WIDGET_RUNTIME_MODE` | `preview` | `production` |
| Публичные тексты | тестовые | обычный AI-консультант |
| AI gateway | loopback `127.0.0.1:8787` | loopback `127.0.0.1:8788` за закрытым HTTPS-каналом |
| Заявки | симуляция | рабочий реестр |
| MAX | не отправляется | через существующий outbox |
| Журнал | локальный preview | `/var/lib/rospark-ai-widget/dialogs.sqlite` |

Production-режим не должен запускаться при:

- выключенном рабочем реестре лидов;
- выключенном журнале диалогов;
- незаданном секретном HTTPS gateway;
- невалидном origin;
- handoff-режиме, отличном от `live`.

## 5. Данные и сроки

- идентификатор браузерной сессии живёт в `sessionStorage`;
- контекст разговора ограничен последними сообщениями;
- текст диалога хранится на VPS до 7 дней;
- технические записи и ошибки хранятся до 14 дней;
- рабочая заявка хранится в реестре лидов до 60 дней;
- телефон и имя не передаются в AI-модель;
- заявка создаётся только после отдельного согласия пользователя;
- Андрей и Сергей видят все диалоги и заявки;
- удаление доступно только Андрею;
- Сергей может просматривать, выгружать и обрабатывать данные.

## 6. Заявка из виджета

Обязательные поля:

- имя;
- российский номер телефона;
- объект;
- задача;
- согласие на обработку персональных данных.

После сохранения:

1. заявка получает идентификатор `RSP-XXXXXXXX`;
2. по умолчанию назначается Сергею;
3. диалог связывается с идентификатором заявки без повторного хранения
   имени и телефона в журнале виджета;
4. уведомление ставится в существующий outbox MAX;
5. посетитель получает подтверждение только после успешной регистрации.

## 7. Отказоустойчивость

Если Mac Studio или закрытый канал недоступны, VPS не раскрывает техническую
ошибку и отвечает:

> Сейчас AI-консультант временно не может подготовить подробный ответ.
> Оставьте заявку — специалист РОСПАРК уточнит задачу и свяжется с вами.

После такого ответа кнопка оформления заявки остаётся доступной. Реестр
лидов и служебный кабинет продолжают работать независимо от Mac Studio.

## 8. Граница текущей работы

В рамках подготовки создаются код, миграции, тесты, переменные окружения,
инструкция резервного копирования, включения и отката.

Фактическое переключение публичного VPS, включение `live` и первая реальная
отправка в MAX выполняются только после отдельного финального подтверждения
и production-gate с резервной копией, проверкой SQLite, PM2, systemd,
публичных маршрутов и аварийного отката.
