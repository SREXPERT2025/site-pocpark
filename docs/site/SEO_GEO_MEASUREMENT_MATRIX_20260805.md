## Цель

Отделить техническую готовность сайта от реального результата после релизов
5 августа и выбрать не более трёх существующих страниц для первого
`GEO-CONTENT-001`.

## Conversion-события

Сравнение двух лендингов строится по результату, а не только по клику CTA:

```text
page_view
→ rospark_landing_cta_click / rospark_ai_promo_click
→ rospark_ai_chat_open
→ rospark_ai_first_message_sent
→ rospark_ai_engaged_chat
→ rospark_ai_lead_handoff или успешная форма
```

Разрешённые разрезы: `landing_variant`, `source_section`, безопасная категория
выбранной задачи и pathname без query string. Имена, телефоны, текст вопроса,
UTM и другие персональные данные в события не передаются.

## Правило решения

Страница входит в первый `GEO-CONTENT-001`, только если одновременно:

1. данные содержат дни после 5 августа;
2. запрос соответствует существующей странице и коммерческой задаче;
3. показов достаточно хотя бы для направленного вывода, а не единичного
   наблюдения;
4. улучшение не создаёт дублирующую страницу и каннибализацию;
5. новые факты имеют источник в
   `GEO_CONTENT_SOURCE_INPUT_20260805.md`;
6. выбран пакет максимум из трёх страниц.

До прохождения gate допустимы только read-only срезы, сбор источников и
подготовка проверок. Production-код, внешние цели, лиды и MAX не изменяются.
