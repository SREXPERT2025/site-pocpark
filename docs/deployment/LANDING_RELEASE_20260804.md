- прежний тестовый адрес `/puzzle2` в production перенаправляется на `/parkovka-pod-klyuch`;
- на главной странице добавлен выбор между «Организовать парковку» и
  «Парковка под ключ»;
- обе страницы доступны из группы «С чего начать» в меню «Решения» и из
  футера; контекстные переходы добавлены в решения, оборудование и статьи;
- архивные варианты `/proshche`, `/puzzle`, `/test2`, `/v4-1`, `/v4-2`
  остаются в Git для истории, но в production отвечают `404`;
- test-stand остаётся в режиме preview: формы не отправляют данные, видна
  служебная плашка;
- production-режим: служебные надписи скрыты, обе формы отправляют лид через
  `/api/lead` с защитой от повторной отправки;
- AI-консультант получает контекст выбранной проблемы/функций;
- общий обработчик ссылок AI-консультанта удаляет `%60` и обратные кавычки,
  отображает жирный Markdown и использует внутреннюю навигацию;
- GA4 `G-3Z9KNN3MMK` и Яндекс Метрика `110980303` подключаются только на
  production-host и только после согласия на аналитику.

Индексация новых рекламных лендингов в первом релизе выключена отдельно от их
публичной доступности. Это позволяет начать рекламный тест без дублирования SEO.

## События и цели

Все события имеют префикс `rospark_`, не содержат имени, телефона, текста
обращения, UTM-значений или иных персональных данных.

Основные конверсии:

| Событие | Назначение | Параметр сравнения |
|---|---|---|
| `rospark_form_success` | лид подтверждён API | `landing_variant` |
| `rospark_ai_lead_handoff` | AI перевёл диалог в рабочую заявку | `landing_variant` |

Микроконверсии:

| Событие | Назначение |
|---|---|
| `rospark_landing_view` | просмотр концепции |
| `rospark_landing_cta_click` | нажатие «Рассчитать парковку» |
| `rospark_landing_choice_change` | выбор задачи/функции без текста клиента |
| `rospark_landing_entry_click` | переход на лендинг из главной, меню, футера или раздела сайта |
| `rospark_form_start` | начало заполнения формы |
| `rospark_form_submit` | попытка отправки |
| `rospark_ai_promo_view` | AI-промо попало в видимую область |
| `rospark_ai_promo_click` | открытие AI из промо |
| `rospark_ai_quick_question_click` | выбран быстрый вопрос |
| `rospark_ai_first_message_sent` | отправлено первое сообщение AI |
| `rospark_ai_engaged_chat` | пользователь отправил второй вопрос в одной AI-сессии |
| `rospark_ai_chat_open` | AI открыт из промо или плавающей кнопки на любой публичной странице |

Общие параметры A/B-сравнения:

- `landing_variant = parkovka | puzzle2`;
- `source_section`;
- `cta_id`;
- `selected_problem` или `selected_functions_count`;
- `session_id` — только случайный технический ID AI-сессии.
- `source_page` — только путь страницы без query string;
- `user_message_count = 2` — фиксированная отметка вовлечённого диалога, без
  текста сообщений.

В Яндекс Метрике после публикации создать четыре новые JavaScript-цели
AI-воронки:

1. `AI — открыт консультант`: `rospark_ai_chat_open`;
2. `AI — отправлен первый вопрос`: `rospark_ai_first_message_sent`;
3. `AI — вовлечённый диалог`: `rospark_ai_engaged_chat`;
4. `AI — создана заявка`: `rospark_ai_lead_handoff`.

Существующая цель `Форма — успешная отправка` (`rospark_form_success`)
сохраняется. В GA4 все четыре AI-события использовать как этапы воронки, а
`rospark_ai_lead_handoff` пометить как основное key event. Первое сообщение и
вовлечённый диалог оставить наблюдаемыми событиями, чтобы не завышать число
бизнес-конверсий.

## Критерий отката

Откат выполняется при любом из условий: `5xx`, неработающий AI, форма не
регистрирует лид, дублируется outbox/MAX, отсутствует аналитический consent
guard, появляется горизонтальная прокрутка или служебная тестовая надпись.
