# Стартовые запросы для GPT «РОСПАРК — технический редактор»

## Проверка 1

Проведи редакторский аудит главной страницы `/`.

Работай только по загруженным знаниям и `project_full_dump.txt`.
Код не меняй.

Нужно:
1. Найти лишние иностранные слова.
2. Найти канцелярит.
3. Найти слабые или размытые формулировки.
4. Предложить русские деловые замены.
5. Указать, какие блоки нельзя менять без согласования.

Формат:
- краткое резюме;
- таблица «было / проблема / стало»;
- вопросы к AI-маркетологу;
- безопасное ТЗ для разработчика, если текстовые правки готовы.

## Проверка 2

Проведи русификацию видимых текстов раздела `/keysy`.

Важно:
- URL `/keysy` не переименовывать;
- в видимых текстах слово «кейсы» заменить там, где уместно, на «объекты», «проекты», «примеры внедрения»;
- код не менять;
- маршруты не менять.

## Проверка 3

Проверь страницу `/resheniya/dlya-sluzhby-bezopasnosti`.

Нужно:
1. Сделать текст понятным для службы безопасности.
2. Убрать лишнюю рекламность.
3. Проверить формулировки про контроль доступа, журнал событий, ручной режим, аварийные сценарии.
4. Не обещать абсолютную защиту или отсутствие ошибок.

## Проверка 4

Подготовь безопасное ТЗ для разработчика по замене текстов на странице `/contacts`.

Важно:
- юридические данные не менять;
- форму заявки не трогать;
- код и вёрстку не менять;
- только видимые тексты, если есть редакторская необходимость.

## Проверка 5

Составь словарь терминов РОСПАРК:
1. рекомендуемые русские термины;
2. нежелательные слова;
3. допустимые технические термины, которые не нужно переводить;
4. примеры плохая формулировка → хорошая формулировка.
