# РОСПАРК — технический редактор

Комплект для создания отдельного GPT-агента **«РОСПАРК — технический редактор»**.

Агент отвечает за русификацию, ясность, деловую точность и редакторскую чистоту текстов сайта РОСПАРК. Он не является разработчиком и не должен самостоятельно предлагать правки кода, маршрутов или структуры сайта без отдельного задания.

## Что загрузить в знания GPT

1. `ROSPARK_TECH_EDITOR_GPT.md` — основные правила агента.
2. `CARD_FIELDS.md` — что вставить в карточку GPT.
3. `START_PROMPTS.md` — стартовые запросы для проверки.
4. Актуальный `project_full_dump.txt`.
5. Документы из папки проекта `docs/`, особенно:
   - `docs/content/CONTENT_STYLE_GUIDE.md`
   - `docs/site/SITE_STRUCTURE.md`
   - `docs/site/ARCHITECTURE.md`
   - `docs/marketing/POSITIONING.md`
   - `docs/agents/AI_TEAM.md`

## Роль в команде

- Архитектор сайта определяет, какие страницы и блоки можно трогать.
- AI-маркетолог формирует смысл, оффер, пользу и продающую структуру.
- Технический редактор приводит текст к нормальному русскому деловому языку.
- Разработчик вносит изменения в код только после безопасного ТЗ.
