# Рабочий процесс агента «РОСПАРК — Архитектор сайта»

> Актуальный контекст находится в
> `docs/agents/CURRENT_PROJECT_CONTEXT_20260723.md`. Раздел с Windows-командами
> ниже является историческим примером, а не инструкцией для current production.

## 1. Как начинать новую задачу

Для любой задачи агент сначала определяет тип работы:

1. Контентная правка.
2. SEO/GEO-улучшение.
3. Изменение структуры сайта.
4. Дизайн/мобильная адаптация.
5. Кодовая правка.
6. Интеграции заявок.
7. Деплой.
8. Документация.

Затем агент проверяет, какие файлы есть в дампе, и предлагает безопасный первый шаг.

## 2. Стандартный цикл изменения сайта

```text
1. Понять цель.
2. Найти затронутые страницы и компоненты.
3. Поставить checkpoint.
4. Сделать минимальную правку.
5. Собрать проект.
6. Проверить страницы в браузере.
7. Проверить мобильную ширину.
8. Закоммитить.
9. Поставить checkpoint после правки.
10. Выложить на демо-сервер.
```

## 3. Команды для локальной разработки

```bash
git status --short
git branch --show-current
npm run build
npm run dev
```

## 4. Команды для дампа проекта

```bash
python3 collect_code.py
```

Дамп `project_full_dump.txt` должен быть в `.gitignore` и не должен попадать в коммиты.

## 5. Команды для проверки, что дамп игнорируется

```bash
git check-ignore -v project_full_dump.txt
git status --short
```

## 6. Production-выпуск

Старые команды прежнего Windows demo-сервера удалены из рабочего процесса.
Для current production использовать только read-only preflight и ручной
процесс из:

- `docs/production/PRODUCTION_STATE_2026_07_23.md`;
- `docs/deployment/AFTER_DEPLOY_GUEST_DEMO_MAX.md`.

Изменяющие команды формируются после проверки фактических путей, процесса,
порта, env, ветки и SHA и выполняются только с отдельным разрешением.

## 7. Контрольный список перед commit

- `npm run build` проходит.
- Нет случайных файлов в `git status --short`.
- Нет `.env.local`, `.next`, `node_modules`, архивов, дампов.
- Страницы проверены на 400 px.
- Формы заявок визуально не вылезают.
- Тексты не перегружены англицизмами.

## 8. Контрольный список после деплоя

- Главная открывается.
- `/contacts` открывается.
- `/vozmozhnosti` открывается.
- `/oborudovanie/<slug>` открывается.
- `/keysy/<slug>` открывается.
- `/resheniya/...` открываются.
- Мобильное меню открывается и прокручивается.
- Заявка отправляется хотя бы на тесте.
- PM2 показывает `online` для сайта.
