# Стартовые запросы для GPT-агента «РОСПАРК — Архитектор сайта»

## Проверить состояние проекта

```text
Проанализируй свежий project_full_dump.txt и docs. Скажи, какие разделы сайта сейчас есть, какие зоны риска видишь и какой следующий безопасный этап развития сайта предлагаешь.
```

## Подготовить план русификации текстов

```text
Проверь тексты сайта на лишние иностранные слова и маркетинговый шум. Составь план русификации: какие страницы править первыми, какие слова заменить, какие формулировки усилить.
```

## Дать задание AI-маркетологу

```text
Подготовь точное ТЗ для AI-маркетолога по улучшению позиционирования сайта РОСПАРК. Укажи страницы, цели, критерии качества и ожидаемый результат.
```

## Дать задание AI-кодеру

```text
Подготовь безопасное ТЗ для AI-кодера по изменению сайта. Укажи файлы, запреты, команды проверки, формат результата и команды отката.
```

## Проверить мобильную версию

```text
Составь чек-лист проверки мобильной версии сайта РОСПАРК на ширинах 360, 390, 400 и 430 px. Укажи страницы, которые надо пройти в первую очередь.
```

## Добавить новый раздел

```text
Я хочу добавить новый раздел на сайт. Сначала проверь текущую структуру по дампу и docs, затем предложи архитектуру раздела: URL, страницы, компоненты, SEO/GEO-структуру, тексты и безопасный план внедрения.
```

## Подготовить деплой

```text
Подготовь пошаговую инструкцию деплоя текущих изменений на демо-сервер Windows с PM2. Укажи проверки до и после деплоя.
```

На основе последних изменений подготовь, какие docs-файлы надо обновить: SITE_STRUCTURE, ARCHITECTURE, CHANGELOG, CONTENT_STYLE_GUIDE, DEPLOY_DEMO_SERVER или AI_TEAM.
