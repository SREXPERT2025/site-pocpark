# AGENTS.md — правила Codex для сайта РОСПАРК / POCPARK

## Контекст проекта

- Компания: ООО «СР Эксперт».
- Публичный русский бренд: РОСПАРК.
- Публичный английский/латинский бренд: POCPARK.
- Сайт: https://www.роспарк.рф.
- Технический punycode-домен: https://www.xn--80aukedde.xn--p1ai.
- Продукт: автоматизированные парковочные системы.

## Главные запреты

- Не менять `main` напрямую.
- Не делать deploy без явного разрешения директора.
- Не делать push, merge или commit без отдельного разрешения, если это не разрешено задачей.
- Не менять VPS, DNS, SSL, nginx, Caddy, GitHub Actions или production-конфигурацию без отдельного разрешения.
- Не коммитить `.env`, секреты, токены, SSH-ключи и пароли.
- Не публиковать статьи, новости и MAX-посты без согласования.
- Не выдумывать факты, цены, сроки, гарантии, технические характеристики, клиентов и кейсы.
- Не создавать новые публичные материалы с написанием `ROSPARK`; русский язык — `РОСПАРК`, английский язык и латиница — `POCPARK`.

## Git-правила

- `main` — production-ветка.
- `ai-site-dev` — основная AI-ветка.
- `feature/site-YYYYMMDD-task` — функциональные и документационные задачи.
- `fix/site-YYYYMMDD-task` — исправления.
- `content/site-YYYYMMDD-topic` — контентные задачи.
- `release/site-YYYYMMDD` — подготовка релиза.
- Все изменения выполнять через отдельную ветку, diff, проверки и отчет.

## Обязательный протокол

Перед изменениями писать:

1. Цель задачи.
2. Текущую ветку и планируемую ветку.
3. Файлы для изменения.
4. Файлы только для чтения.
5. Риски.
6. План проверки.
7. Нужен ли production-доступ.
8. Нужно ли подтверждение директора.

После изменений писать:

1. Что изменено.
2. Измененные, созданные и удаленные файлы.
3. Diff summary.
4. Команды, которые запускались.
5. Результаты проверок.
6. Остаточные риски.
7. Готовность к commit, merge и deploy.

## Обязательная отчетность

Для любой задачи, где меняются файлы, выполняются проверки или готовится аудит, использовать skill `pocpark-task-reporter` и завершать работу markdown-отчетом во внешней папке:

```text
/Volumes/POCPARK_AI_DATA/POCPARK_SITE_AI/reports/
```

Внешние отчеты из `/Volumes/POCPARK_AI_DATA/POCPARK_SITE_AI/reports/` не добавлять в commit сайта, если директор отдельно не разрешил.
